#  学習アシスタント (Study Assistant)
意志力が弱くてもコツコツと勉強が続けられるよう、「黒歴史の公開」というリスクと「ポイント報酬」を組み合わせた学習習慣プラットフォームです。

##  企画の意図
勉強を先延ばしにしてしまうユーザーに心理的な強制力を与えて学習習慣を形成し、達成感の可視化（ポイント）と現実的な報酬（商品券・クーポン）の提供を通じて、持続的なモチベーションを維持させることを目的としています。

##  主な機能
- **黒歴史の自動アップロード**: 目標を達成できなかった場合、あらかじめ設定しておいたメッセージ（黒歴史）が掲示板に公開されるリスクシステム。
- **ポイント＆リワードショップ**: 学習量に応じて貯めたポイントで、アバター、テーマ、商品券、クーポンなどを交換可能。
- **広告ベースの収益モデル**: 無料サービスの提供でユーザーを確保し、広告を通じて収益を創出。

## 🛠 使用技術
- **Language**: HTML5, CSS3
- **Design**: CSS GridとFlexboxを活用したレスポンシブレイアウトの構築
- **Version Control**: Git / GitHub
