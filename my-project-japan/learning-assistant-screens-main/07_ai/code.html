🤖
承知しました！SQL JOINについて分かりやすく解説します。JOINは2つ以上のテーブルを結合して、データをまとめて表示するための演算です。
1. INNER JOIN (内部結合) — 両方のテーブルに存在するデータのみ取得
2. LEFT JOIN (左外部結合) — 左テーブルの全データ + 右テーブルの合致データ
3. RIGHT JOIN (右外部結合) — 右テーブルの全データ + 左テーブルの合致データ
4. FULL OUTER JOIN (完全外部結合) — 両方のテーブルの全データを取得
SELECT *
FROM TableA
INNER JOIN TableB ON A.id = B.id;
