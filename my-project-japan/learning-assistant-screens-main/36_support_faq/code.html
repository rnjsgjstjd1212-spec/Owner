🔒 封印 黒歴史封印システムは、正確にはどのような仕組みですか？
△

黒歴史封印システムは3段階で動作します：

  1. 会員登録またはマイページから黒歴史コンテンツ（写真・動画・反省文・音声）を封印所にアップロード
  2. 学習目標を設定し、公開トリガー（週間学習時間・連続出席・試験D-dayなど）条件を選択
  3. 学習目標未達成時、安全モニタリングを経て設定された公開対象（SNS・知人）へ自動公開

封印コンテンツは学習成功時に安全に保管され、24時間後に自動削除されます。

🔒 封印 封印された黒歴史が公開される正確な条件は何ですか？
△

公開トリガーは封印時にユーザーが直接選択します：

  • 週間学習目標未達成（例：20時間/週）
  • 連続出席が途切れる（例：3日以上）
  • 試験D-dayまでの累積学習時間不足
  • 月間累積学習時間不足

各トリガーの危険度への寄与度は、ペナルティ危険度（P-FE-MY-10）画面からリアルタイムで確認可能です。危険度が100%に達すると、次回の検証タイミングで自動公開されます。
